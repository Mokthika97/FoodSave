About FoodSave

Making surplus food useful.

FoodSave is a food waste management project that connects people who have surplus food with users who can claim it for distribution.

Terms & Conditions

Last updated: September 2026

1. Use of FoodSave

FoodSave is an educational food-sharing platform demo. Users should provide accurate information when creating accounts and food donations.

2. Food Information

Donors are responsible for providing accurate food name, quantity, description, location and expiry information. Users should check food condition and suitability before accepting any donation.

3. User Conduct

Users must not misuse the platform, provide misleading information, attempt unauthorized access, or use the application for unlawful activity.

4. Claims and Donations

A food claim records an intended claim in this demo. FoodSave does not guarantee delivery, food quality, safety, availability or successful distribution.

5. Admin Access

Administrative features are intended only for authorized administrators. Users must not attempt to access or modify admin-only features.

6. Changes

These terms may be updated as the project develops. Users should review the latest version before continuing to use the demo.

Privacy

Privacy Policy

Last updated: September 2026

1. Information Stored

The demo can store your name, email, password, city, food donation details, claim details and optional browser location information.

2. Where Information Is Stored

This version of FoodSave stores data in your browser's Local Storage. It is not a production database.

3. Location

GPS location is optional and is requested only when you choose a location feature.

4. How Information Is Used

Stored information is used to provide login, role-based access, food search, donation, claiming, history and admin dashboard features.

5. Demo Limitation

Do not use real sensitive information or real passwords in this academic demo. A production version would require secure server-side authentication, encrypted password storage and proper security controls.

6. Clearing Data

Because this version uses Local Storage, clearing the browser's site data can remove locally stored FoodSave information.
